セットアップ（あと1ステップ）

Google の認証情報ファイルがまだ置かれていません。以下を行ってください。

  1. Google Cloud Console でプロジェクト作成
  2. 「YouTube Data API v3」を有効化
  3. OAuth同意画面を設定（外部／自分をテストユーザーに追加）
  4. 認証情報 → OAuthクライアントID（種類＝ウェブアプリ）を作成
  5. 「承認済みのリダイレクトURI」に http://localhost:8080/oauth2callback を追加
  6. JSONをダウンロードし、client_secret.json という名前で このフォルダ（multipost/）に置く
  7. このページを再読み込み
